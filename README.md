# Race-Strategy-Simulator

An interactive motorsport-themed game, created for STEM outreach workshops, that introduces engineering decision-making through a simple exploration of race strategy.

Designed with the purpose of delivering to children (ages 9-12) during school visits, this simulator allows users to control tyre compounds, driver style and pit-stop timing in response to changing race conditions.

The simulation is a simple closed decision loop. Each choice influences future options and pit stops are required when defined limits are exceeded. Therefore, lap time, tyre wear, fuel usage and race performance are all impacted by the users' decisions. 

To make the workshop conceptually accessible to children aged 9-12, the simulator deliberately uses simplified race-strategy relationships rather than a high-fidelity vehicle model.
